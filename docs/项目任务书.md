# 项目任务书

**软件体系结构课程实验 · 多智能体智能办公汇报系统**

为部门负责人生成一份可以复核的季度工作汇报。使用者提交需求、选择合成资料，系统完成规划、统计、撰写和审核。教师可以沿报告中的记录编号核对原始数据，并查看一次退回修订如何改变最终结果。

## 工作范围

| 工作包 | 责任安排 | 交付及验收 |
| --- | --- | --- |
| 需求、运行与编排 | A，协调与集成 | 五角色沿图执行。缺少必需输入时停在待补充状态，每轮交接可查。 |
| 大纲与资料统计 | B，规划与数据 | 本地 CSV 按部门和季度过滤。TXT 摘录保留行号，每项统计保留口径、记录 ID 和快照哈希。 |
| 写作、审核与演示 | C，报告与界面 | 展示草稿、审核问题与来源，仅审核通过的当前版本开放 Markdown 下载。 |
| 联调与课程交付 | 三人共同复核 | 对照两个正常场景及一次返工记录复算结果，核对架构图、运行说明和实验报告。个人贡献由本人签认。 |

以上为任务分配。组员姓名、学号、个人总结和交叉复现结果由参加课程的成员据实补入提交表。

## 实施安排

沿用指导书的 30 学时安排，每阶段计划 6 学时。下表中的学时用于课程排期，实际服务耗时见实验报告。

| 阶段 | 工作内容 | 阶段出口 |
| --- | --- | --- |
| M1 环境 | 固定依赖，接入模型，探测文本、JSON 和工具往返 | 环境清单和协议探测日志 |
| M2 单角色 | 定义五个角色的输入输出，单独核对统计与审核 | 业务契约、角色代码、记录 |
| M3 集成 | 用状态图串起技术部和行政部需求 | 两份可追溯的季度汇报 |
| M4 异常与界面 | 注入数值错误，测试资料缺失、服务失败、返工上限和下载 | 轮次草稿、测试与界面截图 |
| M5 交付 | 整理部署说明、实验报告和体系结构分析，组员交叉复现 | 课程材料、运行证据、个人签认 |

## 现场验收

1. 启动工作台，选择技术部第二季度。核对 5 个项目中 3 个完成、出勤率 96.00%、成果 4 项。在“来源核对”中找到项目记录 P01 至 P05。
2. 切换行政部第一季度。核对满意反馈 17 条、样本 20 条、满意度 85.00%。打开文字摘录，说明回执延迟来自服务台记录。
3. 查看“审核返工实验”。指认被改动的初稿、审核意见、返回角色及重新审核的版本；核对最终草稿指纹。
4. 在已配置模型的设备生成一份新报告。取消所需 CSV 的选择后另开一次运行，核对系统提示的缺项以及下载按钮状态。
5. 结合组件图和部署图说明模型服务、统计工具、状态与用户界面的部署边界。用时序图解释审核退回后哪些步骤需要重跑。
