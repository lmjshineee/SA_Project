## 1 接入选择

用户选择 OpenCode Go 的 DeepSeek Flash。依据 [Go 官方文档](https://opencode.ai/docs/go/)（本次核对日期：2026年10月28日），默认配置如下：

| 项目 | 配置 |
| --- | --- |
| provider | `opencode-go` |
| model | `deepseek-v4.1-flash` |
| base_url | `https://opencode.ai/inference/go/openai/v1` |
| 协议 | Chat Completions |
| 参数 | temperature 0；max_tokens 4096；HTTP 客户端超时参数 60 秒 |
| 凭据 | 本机 `.env` 或环境变量 `MODEL_API_KEY` |

适配器携带独立 User-Agent，并在一次验证的四次请求中保持 `x-opencode-session` 一致。官方文档当前要求 DeepSeek 的工作区允许 Global 区域；本次账号已完成真实调用，但未检查或修改工作区隐私设置。Go 的服务定位是编码 Agent，本批次采用代码测试探针；后续办公场景是否适用仍需确认。

## 2 已实现的范围

1. Python 3.11 的 `src` 包、固定运行与验证依赖、本机配置示例。
2. 最小模型适配器：文本、JSON mode 和原生工具消息；识别认证/权限、连接、超时、截断及无效结构，不自动重试或回退。
3. `office-verify --environment`：查看环境、依赖、Git 状态及源文件 SHA-256，不调用模型。
4. `office-verify --live`：验证文本、严格 JSON 内容、工具往返，最多四次请求，失败即停止。
5. 本机探针记录：脱敏配置、模型实际返回标识、事件、用量与汇总；不保存内部推理内容。无用量时保留 `null`，费用未核算。
6. `mock` 测试：覆盖成功协议、失败路径、权限边界、证据隔离和密钥脱敏，不作为真实模型实验结果。

JSON mode 通过 `response_format={"type":"json_object"}` 请求，内容由本地 Pydantic 模型严格校验。本批次没有声称服务支持原生 JSON Schema 强制输出。工具为合成样例 `sum_integers([3, 5])`，不是业务数据工具；随机核验标记在工具实际执行后生成，模型必须正确回传该标记。
